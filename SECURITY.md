# Security policy

## Supported versions

ParkAlong is an early open-source demo. Security fixes are applied to the latest revision on `main`.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. If that surface is unavailable, open a minimal issue asking the maintainers for a private contact channel—do not publish exploit details, personal data, credentials, or precise private locations in a public issue.

Useful reports include the affected revision, iOS version, reproduction steps, impact, and a suggested mitigation when known.

## Scope

ParkAlong has no account system or first-party backend. Relevant reports can still include unsafe URL handling, privacy leaks, insecure local storage, dependency issues, or unexpected disclosure through City API and MapKit requests.
