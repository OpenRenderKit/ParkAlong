# Generated parking data

These compact artifacts are generated from City of Melbourne open data and bundled so ParkAlong can join stable zone metadata locally and provide a clearly labelled historical fallback:

- `zone_metadata.json`
- `restrictions.json`
- `historical_availability.json`

Regenerate them with the scripts documented in the repository README. Do not manually edit them or commit the raw 2019 archive.
